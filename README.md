# Telegram-бот: новости и умный чат

Бот собирает новости из выбранных источников, отвечает на вопросы через твой собственный ключ нейросети, читает текстовые файлы и рисует картинки.

## Как начать
1. Открой бота и нажми /start.
2. /start и /help покажут список команд, доступных тебе. /menu: меню по темам кнопками.

## Новости
- /news: свежее из источников; /sources: откуда берутся новости
- /subscribe on|off: рассылка (по умолчанию выключена); /newstime 09:30: когда присылать (по Москве, до 4 времён: /newstime 09:00 21:00)
- /newsformat ai|short: с кратким пересказом или только заголовки
- /removesource N: убрать свой источник

## Свой ИИ
Бот отвечает через ключ нейросети, который ты подключаешь сам.
- /apikey add КЛЮЧ: подключить (сообщение с ключом бот удаляет, ключ хранится зашифрованным). Провайдер определяется по началу ключа; можно и так: /apikey add groq КЛЮЧ
- /apikey providers: список провайдеров и где взять бесплатный ключ (Groq, Google, Cerebras, Mistral, SambaNova, GitHub Models, OpenRouter и др.)
- /model: выбрать модель; /models: список бесплатных моделей; /apikey list, /apikey del N: список и удаление

## Файлы, картинки, перенос диалога
- Текстовый файл (txt, md, csv, json, код) до 20 МБ: пришли с подписью, что сделать
- /img описание: нарисовать картинку (пауза 60 секунд между картинками)
- /export: выгрузить диалог файлом; файл с подписью /import: загрузить диалог (из бота, Claude, ChatGPT)

## Прочее
/clear: очистить диалог, /mode coder|chat|auto: режим, /newchat: новый чат с сутью прошлого, /rules: правила, /whatsnew: что нового. Старые названия команд (/key, /sub, /time и др.) тоже работают.

## Правила и приватность
Бот для 13+. Не присылай пароли и чужие личные данные. Сообщения проходят автоматическую проверку, при 3 нарушениях доступ закрывается (/rules). Бесплатные ИИ-сервисы могут сохранять запросы: личное туда не отправляй.
