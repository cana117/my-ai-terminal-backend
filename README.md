# Telegram-бот: новости и умный чат

Сервис на FastAPI: Telegram-бот (новости из источников по расписанию, чат с нейросетью через ключи самих пользователей) и простая веб-страница.

## Запуск
1. Создай бота в @BotFather и получи токен.
2. Создай веб-сервис на Render из этого репозитория.
   - Build: `pip install -r requirements.txt`
   - Start: `uvicorn app:app --host 0.0.0.0 --port $PORT`
3. В Render, раздел Environment, задай переменные из `env.example` (минимум `BOT_TOKEN`, `ADMIN_ID`, `ENC_KEY`).
4. Мастер-ключ `ENC_KEY` создаётся на своём компьютере: `python app.py genkey`. Храни его копию отдельно: без него зашифрованные данные не открыть.

## Свой ИИ
Каждый человек подключает свой ключ командой `/key add провайдер КЛЮЧ` (Groq, Google, Cerebras, Mistral, SambaNova, GitHub Models, OpenRouter и любой OpenAI-совместимый через `custom`), модель выбирается командой `/model`. Файлы до 20 МБ, генерация картинок и перенос диалога доступны всем.

## Безопасность
- Секреты хранятся только в переменных окружения хостинга, в репозитории их нет.
- Ключи пользователей и бэкапы хранятся в зашифрованном виде.
- Не публикуй `.env`, файлы `.db` и ключи.
