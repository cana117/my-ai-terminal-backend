# MY_AI (alpha 0.01)

Telegram-бот на Python (FastAPI) с мини-приложением: чат, новости, терминал для админа.

## Версии
Начинается с **alpha 0.01**. Малое обновление +0.01, побольше +0.1, крупное +1. Меняй `VERSION` и добавляй строку в `CHANGELOG` в начале `app.py`.

## Запуск на Render
1. Залей файлы в GitHub (без `.env`!).
2. Render: New Web Service. Build: `pip install -r requirements.txt`. Start: `uvicorn app:app --host 0.0.0.0 --port $PORT`.
3. В Environment добавь переменные из `env.example` (минимум `BOT_TOKEN`, `ADMIN_ID`, `ENC_KEY`).
4. Напиши боту `/start`, потом `/admin_check`: он покажет, что работает, а что нет.
5. Бесплатный Render засыпает: бот сам пингует себя раз в 5 минут, но первый запрос после сна может быть медленным.

## Как подключить ИИ (для людей)
`/apikey_providers`, создать ключ на сайте провайдера, `/apikey_add НОМЕР КЛЮЧ`. Ключ принимается только этой командой, сообщение сразу удаляется. Любое другое сообщение с ключом бот удаляет и пишет «так нельзя» (без наказания). Ключи хранятся зашифрованными (у каждого человека свой ключ шифрования, он заперт `ENC_KEY`).

## Терминал
Скачивать ничего не нужно. В Telegram: команда `/terminal`, кнопка «Открыть терминал». На сайте: открой адрес сервиса, вкладка «терминал», введи `ADMIN_TOKEN` (он только в памяти страницы).

## Классы и задержки
admin 0 с, tester3 10, tester2 15, tester1 20, остальные 30 (если классов несколько, берётся самая короткая). Настраивается в `DELAY_BY_CLASS`. Каждое назначение класса это отдельная запись, человек может быть в нескольких классах. Лишние команды молча игнорируются.

## Наказания тестеров и кодеров
1 выговор, 2 снятие на месяц, 3 на год, 4 навсегда, 5 бан. Защищённые (`/protect_add`, `PROTECTED_IDS`) автоматически не банятся и не снимаются: только запись в лог, решаешь ты. После любого бана человек остаётся под усиленным контролем (проверяются все его сообщения).

## Подтверждения
Награды (`/reward_add`) и подарки (`/gift_send`) всегда с карточкой и кнопками, получатель по ID или @ (в карточке виден ID). Кнопка одноразовая, живёт 5 минут.

## Секции для кодеров
Файл разбит на секции `# === SECTION: имя ===`. Задача кодеру (`/coder_task ID секции | описание`) отправляет только выбранные секции, секреты вырезаются.

## Не проверено
Код проверен автотестами без сети (логика, права, шифрование, подтверждения). Реальные запросы к Telegram, провайдерам ИИ и сайтам новостей нужно проверить после запуска. Адреса провайдеров и запасные модели вынесены в константы вверху `app.py`.
