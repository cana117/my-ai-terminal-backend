# Telegram-бот: новости и умный чат

Новости из источников, чат через твой ключ нейросети, режимы chat/coder.

- /start, /help: список команд, /rules: правила (13+)
- /news, /sources, /subscribe on|off, /newstime 09:30, /newsformat ai|short
- /apikey providers|add|list|del: подключить свой ИИ (ключ шифруется, сообщение удаляется)
- /model_list, /model_N, /models: выбор модели
- /mode coder|chat|auto, /clear, /newchat

Не присылай пароли и чужие личные данные. Сообщения проходят автоматическую проверку, 3 нарушения закрывают доступ. Бесплатные ИИ-сервисы могут сохранять запросы.
