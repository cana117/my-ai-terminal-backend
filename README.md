# Telegram-бот: новости и умный чат

Бот собирает новости из выбранных источников, отвечает на вопросы через твой собственный ключ нейросети, читает текстовые файлы и рисует картинки.

## Как начать
1. Открой бота и нажми /start.
2. /help покажет все команды.

## Новости
- /news: свежее из источников
- /addsource ссылка: добавить источник (RSS, канал Telegram, YouTube); /sources: список; /delsource N: удалить
- /sub on|off: рассылка; /time 09:00 21:00: когда присылать (по Москве)
- /format ai|short: с кратким пересказом или только заголовки

## Свой ИИ
Бот отвечает через ключ нейросети, который ты подключаешь сам.
- /key providers: список провайдеров и где взять бесплатный ключ (Groq, Google, Cerebras, Mistral, SambaNova, GitHub Models, OpenRouter и др.)
- /key add провайдер КЛЮЧ: подключить (сообщение с ключом бот удаляет, ключ хранится зашифрованным)
- /model: выбрать модель; /key list, /key del N: список и удаление

## Файлы, картинки, перенос диалога
- Текстовый файл (txt, md, csv, json, код) до 20 МБ: пришли с подписью, что сделать
- /img описание: нарисовать картинку (пауза 60 секунд между картинками)
- /export: выгрузить диалог файлом; файл с подписью /import: загрузить диалог (из бота, Claude, ChatGPT)

## Прочее
/clear: очистить диалог, /agent coder|chat|auto: режим, /rules: правила, /updates: что нового.

## Правила и приватность
Бот для 13+. Не присылай пароли и чужие личные данные. Сообщения проходят автоматическую проверку, при 3 нарушениях доступ закрывается (/rules). Бесплатные ИИ-сервисы могут сохранять запросы: личное туда не отправляй.
